# IStruct Beam / IStruct Vigas 

---

# 📌 Sobre o Projeto

O **IStruct Beam** é um software estrutural open-source focado no dimensionamento de vigas de concreto armado.

O objetivo do projeto é fornecer uma ferramenta:

- leve
- gratuita
- didática
- visual
- extensível
- voltada para engenheiros civis brasileiros

O sistema está sendo desenvolvido com foco em:

✅ produtividade

✅ clareza dos resultados

✅ memorial de cálculo

✅ detalhamento simplificado

✅ interface gráfica moderna

✅ exportação de documentação técnica

---

# 🚀 Recursos Atuais

## ✅ Análise estrutural

- Viga biapoiada
- Carga distribuída
- Cálculo automático de:
  - Momento fletor
  - Cortante

---

## ✅ Dimensionamento à flexão

- Concreto armado conforme NBR 6118
- Verificação de domínio
- Armadura mínima
- Dimensionamento automático
- Escolha simplificada de barras

---

## ✅ Verificação ao cisalhamento

- Verificação de Vc
- Verificação de Vrd2
- Dimensionamento simplificado de estribos
- Espaçamento automático

---

## ✅ Interface gráfica

- Desenvolvida em PyQt5
- Interface limpa e objetiva
- Inputs simplificados
- Fluxo rápido de cálculo

---

## ✅ Detalhamento gráfico

- Desenho automático da seção transversal
- Representação das barras
- Estribos
- Cotas
- Armadura adotada

---

## ✅ Memorial de cálculo

- Janela dedicada
- Relatório técnico automático
- Organização dos resultados

---

## ✅ Exportação PDF

- Geração automática de memorial
- Layout profissional
- Base para documentação técnica

# ⚙️ Instalação

## 1️⃣ Clone o repositório

```bash

```

---

```bash
cd istruct-beam
```

---

## 3️⃣ Instale as dependências

```bash

```
